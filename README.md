**namefade** — forgetting someone's name seconds after they tell you it.

One new English word, defined in a single clear line. Everyone has lived it: you are introduced, you shake the hand, and by the time the sentence ends the name is already gone. English has no single word for that lapse, so this entry coins one — *name* + *fade*, two plain words joined the way English grows its own vocabulary.

## The entry

`main.ts` (Node 22, standard library only) writes the word and its definition to `/output/entry.txt`, the one artifact the gate checks (1–140 characters of UTF-8 text) and the judge reads. It refuses to write anything that would fail the gate instead of handing in a bad file.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
